Build ứng dụng thành file .exe để tối ưu (không chạy bằng go run trên production):
go build -ldflags "-s -w" -o server.exe ./cmd/server/main.go
(Flag -s -w giúp giảm dung lượng file binary).

Chạy file:
./server.exe
